A full-stack Todo application built with **FastAPI**, **React**, **PostgreSQL**, and **Redis** featuring caching, authentication, and real-time updates.

## ✨ Features

- ✅ **CRUD Operations** - Create, Read, Update, Delete todos
- 🔐 **JWT Authentication** - Secure user authentication
- 🗄️ **PostgreSQL** - Primary database for persistent storage
- ⚡ **Redis Cache** - Caching for improved performance
- 📱 **Responsive Design** - Works on desktop and mobile
- 🔄 **Real-time Updates** - Automatic UI refresh
- 📚 **Auto-generated API Docs** - Interactive Swagger UI
- 🐳 **Dockerized** - Easy setup with Docker Compose

## 🛠️ Tech Stack

### Backend
- **FastAPI** - Modern Python web framework
- **SQLAlchemy** - ORM for PostgreSQL
- **Pydantic** - Data validation
- **Alembic** - Database migrations
- **Redis** - Caching layer
- **JWT** - Authentication

### Frontend
- **Next.js** - React framework with SSR, routing, and API routes
- **React** - UI library with concurrent features
- **TypeScript** - Type safety and better DX
- **Tailwind CSS** - Utility-first CSS framework
- **Mantine** - Comprehensive UI component library
- **Radix UI** - Accessible, unstyled components
- **React Hook Form** - Performant form management
- **Zod** - Schema validation
- **Lucide React** - Beautiful icon set
